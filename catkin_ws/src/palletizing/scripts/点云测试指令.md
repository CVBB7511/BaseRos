下面是点云测试的完整终端流程。

**终端 1：ROS Master**
```bash
source /opt/ros/noetic/setup.bash
roscore
```

**终端 2：启动真机点云测试系统**
```bash
source /opt/ros/noetic/setup.bash
source /home/yubowen/BaseRos/catkin_ws/devel/setup.bash

roslaunch gazebosim_demo pointcloud_detection_test_real.launch \
  map_file:=/home/yubowen/BaseRos/real_maps/real_map.yaml
```

该 launch 会同时启动 `pointcloud_detection_test.py` 和 RViz，不需要再单独执行 `rosrun palletizing pointcloud_detection_test.py`。启动后在 RViz 里用 `2D Pose Estimate` 设置机器人初始位姿。

**终端 3：手动控制底盘**
```bash
source /opt/ros/noetic/setup.bash
source /home/yubowen/BaseRos/catkin_ws/devel/setup.bash

rosrun gazebosim_demo vel_ctrl_node.py
```

移动到底盘合适位置后，按空格停止。

**RViz 可视化调试**

终端 2 默认使用 `start_rviz:=true`，会自动打开点云测试专用 RViz 布局，无需再手动点击 `Add`。布局预先加载：

- RGB 图像：`/kinect2/sd/image_color_rect`
- Kinect 原始点云：`/kinect2/sd/points`
- 桌面平面（绿色）：`/segmented_plane`
- 分割物体（黄色）：`/segmented_objects`
- 真实任务多帧融合后的识别框与标签（青色）：`/pointcloud_test/fused_marker`
- TF、地图、激光雷达、导航路径和定位粒子

如果 RViz 被关闭，可以单独恢复同一布局：

```bash
source /opt/ros/noetic/setup.bash
source /home/yubowen/BaseRos/catkin_ws/devel/setup.bash

rviz -d /home/yubowen/BaseRos/catkin_ws/src/gazebosim_demo/rviz/pointcloud_detection_test.rviz
```

推荐先看 `/kinect2/sd/points` 是否正常，再触发检测：

```bash
rosservice call /pointcloud_test/detect_here "{}"
```

触发检测后再看 `/segmented_plane`、`/segmented_objects`、`/pointcloud_test/fused_marker`。青色框是与 `palletizing_executor.py` 相同的多帧采样、位置融合和稳定性过滤结果，会保留到下一轮有效结果或手动停止检测。

如果 `/kinect2/sd/points` 没有数据，先检查 Kinect：

```bash
rostopic hz /kinect2/sd/points
```

如果 `/segmented_objects` 中几个物体粘成一大块，通常要调整观察角度、拉开物体间距，或减小 `cluster_tolerance`。

**终端 4：启动当前位置连续点云识别**
```bash
source /opt/ros/noetic/setup.bash
source /home/yubowen/BaseRos/catkin_ws/devel/setup.bash

rosservice call /pointcloud_test/detect_here "{}"
```

调用一次后会重复执行真实任务的检测周期：底盘停稳、收集 5 个非空样本、多帧融合、稳定性过滤，失败时最多重试 2 次。RViz 显示本轮最终融合结果，而不是 C++ 检测器的瞬时单帧框。

为了和真实任务一致，每轮检测前会发布零速度使底盘停稳。需要更换观察位置时，先停止检测，在终端 3 移动底盘，停稳后再重新调用 `detect_here`。

停止识别并清除检测框：

```bash
rosservice call /pointcloud_test/stop_detection "{}"
```

如果你想自动导航到 SRC DESK 前再连续识别，终端 4 改用：

```bash
rosservice call /pointcloud_test/start "{}"
```

常用检查命令：

```bash
rostopic echo /wpb_home/objects_3d
```

```bash
rostopic hz /kinect2/sd/points
```

```bash
rosnode list
```
