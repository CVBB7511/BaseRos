# 码垛机器人点云视觉识别方案

## 1. 目标

当前方案用于识别桌面上的 10 cm 和 15 cm 立方体，输出物体类型、位置和尺寸，供机械臂抓取和码垛排序使用。

整体分为两层：

1. C++ 节点负责单帧点云的桌面分割、离群滤波、聚类和几何分类。
2. Python 共享组件负责多帧目标关联、稳定性过滤和中值融合。

点云测试和真实码垛任务共用同一份 Python 检测逻辑，并使用相同的真机参数。

## 2. 代码结构

- 单帧点云处理：`wpb_home/wpb_home_behaviors/src/wpb_home_objects_3d.cpp`
- 共享多帧检测：`palletizing/src/palletizing_detection/object_detection.py`
- 真实码垛执行：`palletizing/scripts/palletizing_executor.py`
- 无机械臂测试：`palletizing/scripts/pointcloud_detection_test.py`
- 测试 launch：`gazebosim_demo/launch/pointcloud_detection_test_real.launch`
- 真实任务 launch：`gazebosim_demo/launch/palletizing_execute_real.launch`

## 3. 坐标系与输入

输入为 `/kinect2/sd/points`。C++ 节点先通过 TF 将点云转换到 `base_footprint`：

- X：机器人前方。
- Y：机器人左方。
- Z：竖直向上。

相机前右偏移、高度和俯仰角应由 URDF/TF 表达。输出已在机器人坐标系中，不应再人工叠加相机横向偏移。

## 4. C++ 单帧处理

### 4.1 启停和频率

`wpb_home_objects_3d` 收到 `object_detect start` 后处理点云，收到 `object_detect stop` 后停止并清除单帧标记。处理间隔最小为 0.5 s，约 2 Hz。

### 4.2 感兴趣区域

PassThrough 保留范围：

| 轴 | 范围 |
|---|---:|
| X | 0.0--1.5 m |
| Y | -1.5--1.5 m |
| Z | 0.3--1.5 m |

### 4.3 桌面检测

使用 PCL RANSAC 寻找近似水平面：

- 模型：`SACMODEL_PERPENDICULAR_PLANE`
- 参考法向：Z 轴
- 允许倾角：10°
- 内点距离阈值：5 mm
- 桌面高度：0.60--0.85 m

程序会迭代剔除不符合高度的大平面，直到找到目标桌面。

### 4.4 桌面上物体提取

对桌面计算二维凸包，然后用多边形棱柱提取桌面上方约 3--20 cm 的点：

```cpp
prism.setHeightLimits(-0.20, -0.03);
```

由于最低 3 cm 被切除，尺寸判定时使用 `cube_prism_bottom_cut=0.03 m` 补回物体高度。

### 4.5 飞点和拖影滤波

在聚类前使用 StatisticalOutlierRemoval：

| 参数 | 当前值 |
|---|---:|
| `filter_object_outliers` | `true` |
| `outlier_mean_k` | 20 |
| `outlier_stddev` | 1.0 |

该步骤主要清理 Kinect 在物体边缘产生的稀疏飞点和 X 方向拖影。`/segmented_objects` 发布该滤波之后的物体点云。

### 4.6 欧式聚类

| 参数 | 真机值 |
|---|---:|
| `cluster_tolerance` | 0.04 m |
| `cluster_min_size` | 500 points |
| `cluster_max_size` | 10000000 points |

物体太近，或中间存在连续拖影时，可能被聚类为同一个物体。

### 4.7 稳健边界框

为避免少量残留飞点拉大识别框：

- X/Y 边界使用 5%--95% 分位点，`bbox_trim_ratio=0.05`。
- Z 边界仍使用最小/最大值，避免裁剪影响 10/15 cm 高度分类。

### 4.8 10 cm/15 cm 分类

| 参数 | 真机值 |
|---|---:|
| `cube_size_small` | 0.10 m |
| `cube_size_large` | 0.15 m |
| `cube_size_tolerance` | 0.07 m |
| `cube_min_x_size` | 0.03 m |
| `cube_max_x_size` | 0.35 m |
| `cube_shape_ratio` | 2.3 |
| `cube_prism_bottom_cut` | 0.03 m |

校正高度为：

```text
corrected_size_z = measured_size_z + 0.03 m
```

分类主要比较 Y 尺寸和校正后的 Z 尺寸与 0.10/0.15 m 的误差。X 方向容易受深度遮挡和拖影影响，当前主要用于排除明显不合理的簇。

### 4.9 单帧输出

```text
x = xMax
y = (yMin + yMax) / 2
z = zMin
```

X 不是几何中心，而是现有抓取接口约定的边界坐标。修改这一定义会直接改变机械臂抓取 X 坐标，必须联合真机验证。

单帧结果通过 `/wpb_home/objects_3d` 发布。

## 5. Python 多帧融合

`ObjectDetectionMixin` 是测试节点和真实码垛节点共用的唯一任务级检测实现。

| 参数 | 真机值 |
|---|---:|
| `detect_timeout` | 5.0 s |
| `detect_min_samples` | 3 |
| `detect_fusion_samples` | 5 |
| `detect_fusion_min_hits` | 2 |
| `detect_fusion_merge_xy` | 0.08 m |
| `detect_retry_count` | 2 |
| `detect_retry_settle` | 0.50 s |

流程：

1. 发布零速度，等待底盘和点云稳定。
2. 发送 `object_detect start`。
3. 最多收集 5 个非空单帧样本，最长等待 5 s。
4. 根据 XY 距离将多帧目标关联到轨迹，合并阈值为 8 cm。
5. 只保留采样窗口中至少出现 2 次的轨迹。
6. 类型使用多数投票，位置和尺寸使用中值。
7. 发送 `object_detect stop`。
8. 失败时最多重试 2 次。

超时时如果已存在满足最少命中数的稳定轨迹，仍会输出融合结果。

## 6. RViz 显示含义

| 显示项 | Topic | 含义 |
|---|---|---|
| 原始点云 | `/kinect2/sd/points` | Kinect 彩色点云 |
| 桌面平面 | `/segmented_plane` | RANSAC 桌面，绿色 |
| 物体点云 | `/segmented_objects` | 棱柱提取且离群滤波后的点，黄色 |
| 单帧框 | `/obj_marker` | C++ 瞬时结果，默认关闭 |
| 融合框 | `/pointcloud_test/fused_marker` | Python 多帧最终结果，青色 |

调试时应以青色融合框作为真实任务结果。绿色/黄色点云用于定位问题是发生在平面分割、物体提取还是聚类阶段。

## 7. 测试与真实任务的一致性

```text
palletizing_executor.py
pointcloud_detection_test.py
        |
        v
palletizing_detection/object_detection.py
```

`pointcloud_detection_test.py` 只额外提供连续循环和 RViz 融合框，每轮的采样、融合、超时和重试与真实任务相同。

修改真机参数时，必须同时修改：

```text
pointcloud_detection_test_real.launch
palletizing_execute_real.launch
```

## 8. 建议调试顺序

1. 确认 `/kinect2/sd/points` 没有大面积缺失、跳变或 USB 丢包。
2. 确认 TF 中相机高度、俯仰角和前右偏移正确。
3. 观察 `/segmented_plane` 是否稳定覆盖桌面。
4. 观察 `/segmented_objects` 是否保留完整物体，是否仍有 X 方向拖影。
5. 查看终端的 `size=(x, y, z)` 和 `reject_obj` 日志。
6. 最后观察青色多帧融合框和类型。

机器人移动时点云可能因时间同步和 TF 变化产生拖影。真实任务会在每轮检测前发布零速度并等待底盘稳定，因此调参也应在静止状态下进行。

## 9. 常见问题与调参方向

| 现象 | 优先检查 | 调整方向 |
|---|---|---|
| X 方向框过长 | 物体后方飞点 | 降低 `outlier_stddev`，或小幅提高 `bbox_trim_ratio` |
| 物体点被过度删除 | 黄色点云残缺 | 提高 `outlier_stddev`，或减少 `outlier_mean_k` |
| 两个物体粘连 | 间距与连续拖影 | 减小 `cluster_tolerance` |
| 小物体没有簇 | 单个物体点数 | 降低 `cluster_min_size` |
| 物体时有时无 | 丢包、反光、遮挡 | 先改善观察角度，再调融合命中数 |
| 相邻物体融合为一个 | 中心距离是否小于 8 cm | 减小 `detect_fusion_merge_xy` |
| 10/15 cm 类型混淆 | Y 和校正 Z 尺寸 | 先检查桌面与外参，再调 `cube_size_tolerance` |

调参时每次只改一类参数，并记录同一摆放下的识别数量、尺寸和坐标波动。
